# Implementation Plan

## Phase 1 — Foundation

- Laravel/Inertia/React project setup
- Authentication, roles and permissions
- Settings, districts, categories, statuses and currencies
- Base layout, brand tokens and responsive navigation
- Audit log and document upload foundation

## Phase 2 — Property and tenancy MVP

- Properties and photos
- Units and occupancy status
- Tenant records
- Leases, deposits, due day and expiry alerts
- Property/unit detail pages

## Phase 3 — Maintenance MVP

- Maintenance requests with photos
- Priority and status workflow
- Vendor/technician directory
- Scheduling and assignment
- Job order execution and completion evidence
- Maintenance history per property and unit

## Phase 4 — Billing and operations

- Quotations and approvals
- Invoices and partial payments
- Expenses and job profit
- Inventory usage and reorder alerts
- Supplier purchases

## Phase 5 — Portals and automation

- Tenant request portal
- Technician mobile workflow
- WhatsApp/SMS notifications
- Lease expiry, payment and warranty reminders
- Reports and exports

## First acceptance test

Create one property with two units, add one tenant and active lease, submit a plumbing maintenance request, assign a technician, create a quote, convert it to a job, record a material, complete the job, issue an invoice, record a partial payment and confirm the activity appears in the property maintenance history.
